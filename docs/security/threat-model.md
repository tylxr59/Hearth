# Threat model

Assets: native HVAC control and power stability; temperatures/schedules/occupancy inferred from state; credentials; recovery images and firmware provenance; HA/MQTT integrity.

Adversaries considered: an unauthenticated LAN peer, device-serial impersonator, malicious or compromised device, compromised MQTT publisher, abusive parser client, malicious update/source artifact and access to logs/backups. Local administrator/root, broker administrator, or authorized manager can control devices and change credentials. Physical tampering and compromised proprietary control firmware are not solved by this host prototype.

| Boundary | Enforcement | Residual risk |
|---|---|---|
| Device to backend | Exact serial + per-device CSPRNG secret; constant-time digest comparison; HTTPS for non-loopback bind. Never auto-enroll based on a serial. | Stock client transport/credential installation unverified; enrollment stays offline/test-only. Stolen bearer-equivalent credentials can impersonate until revoked. |
| Manager to backend | Separate 256-bit Bearer credential; no device role access; no-store responses, no access logs. | One full-privilege local manager role; no multi-user RBAC. Restrict listener/network. |
| MQTT to command engine | TLS certificate validation, broker username/password, explicit ACLs, operation allowlist, capability gates, bounded temperature, MQTT5 retain controls, command expiry. | Broker compromise permits bounded commands. A broker or network outage delays state/commands. Duplicate QoS deliveries may produce equivalent new intents; no physical exactly-once guarantee. |
| Untrusted state | 16 KiB JSON limit, duplicate/NaN rejection, small schemas and no raw bucket persistence. | Does not prove truth of telemetry or firmware version from a compromised device. Connection/resource exhaustion remains possible; router must limit clients. |
| Firmware/tool input | Explicit SHA-256 source manifest; input path/link checks, limited sizes, no shell evaluation or firmware execution; no automatic downloads in build/provision runtime. | Checksums alone do not authenticate a malicious source. Full proprietary image integrity, boot signing, and old native vulnerabilities remain unaddressed. |
| Host filesystem | Credentials exported mode 0600, new private directories mode 0700; registry stores hashes only. Container UID 10001. | Host root and backup readers can compromise secrets. Offline registry editing requires backend shutdown. Disk failure can interrupt enrollment; no cross-file transaction guarantee. |
| Thermostat internet | External isolated VLAN policy, no new default listeners on device, future conditional on-device firewall. | Device firmware has unknown endpoints/services and potential local exploits; filtering is defense in depth, not a firmware fix. |

Safety boundary: backend is supervisory only, with no wire/relay/GPIO/MCU interfaces. Preserve native protective behavior, but it has not been measured. Conservative host command bounds are not a substitute for hardware-specific safety limits, compressor lockout or wiring validation. Do not disable unknown services for cosmetic minimalism.

Privacy: backend persists only serial identifiers, capability inventory and hashes in registry.json. Device bootstrap and admin files contain secrets and are stored only by explicit tooling. Temperature/humidity/state/intent live in memory; MQTT retains last state/discovery and offline availability at the broker. Online availability is a non-retained heartbeat, preventing a broker restart from restoring an old online marker. Broker persistence and HA recorder/history may retain it on disk independently. Revocation removes retained state/discovery for devices observed by the current bridge process; if the bridge was restarted after offline revocation, manually remove their retained topics. No diagnostic history or credential logging is enabled. Runtime library errors go to stderr without request body logging. Configure HA/broker log retention and recorder exclusions; discard commissioning packet captures after review, because captures of any plaintext legacy experiment may contain credentials.
